# Configuração VS Code Resolvida

O projeto foi configurado para funcionar perfeitamente com a extensão de Java do VS Code.
Isto foi feito através da adição de:
1. Um ficheiro `pom.xml` (que torna o projeto compatível com Maven).
2. Uma pasta `.vscode/settings.json` para ajudar o "Java Language Server" a identificar que a pasta fonte (Source Root) é a pasta `engine`.
